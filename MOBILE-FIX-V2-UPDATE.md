# V8 Race Fantasy mobile fix v2

This update specifically targets the remaining phone layout problems.

Fixes:
- Pick Team category buttons A–F now fit on one row on mobile.
- E and F are no longer pushed off-screen.
- Top status banner is now a tiny mobile bar instead of three stacked info boxes.
- Leaderboard mobile summary is compressed into one short row.
- Leaderboard event tabs now scroll sideways as compact pills.
- Leaderboard helper text is hidden on phones.
- Leaderboard desktop cards remain unchanged for larger screens.
- Home page is much shorter on mobile.
- Logged-in users do not see the mobile launch hero anymore because the dashboard already covers it.
- Home page action cards are smaller.
- Home page contact block is hidden on mobile.
- Home page rule cards are tiny on mobile.
- Run-home section is a compact horizontal strip on mobile.
- Current round fantasy stat cards are hidden from the dashboard on phones to reduce scrolling.

No Supabase SQL is needed.
